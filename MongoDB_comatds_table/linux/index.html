История создания Linux

Linux — это семейство Unix-подобных операционных систем с открытым исходным кодом, основанных на одноименном ядре. История Linux началась в 1991 году, когда финский студент Линус Торвальдс (Linus Torvalds), обучавшийся в Университете Хельсинки, разочаровался в ограничениях операционной системы MINIX (учебная Unix-подобная система) и решил написать собственное ядро, совместимое с POSIX.

25 августа 1991 года Линус отправил свое знаменитое письмо в новостную группу компьтерной сети: «Привет всем... Я пишу бесплатную операционную систему (просто хобби, не будет большой и профессиональной, как gnu)...». В сентябре 1991 года была выпущена версия 0.01.

Важнейшую роль в успехе Linux сыграл проект GNU, начатый Ричардом Столлманом в 1983 году. GNU создавал свободное окружение (компиляторы, редакторы, оболочки), но у них не было готового ядра. Объединение ядра Linux и системных утилит GNU привело к созданию полноценной операционной системы, которую правильно называть GNU/Linux.

Руководство по установке Linux на Mac OS


GPT CHAT LINK

Существует три основных способа использовать Linux на компьютерах Apple (как на базе процессоров Intel, так и на базе современных чипов Apple Silicon M1/M2/M3):

  1. Виртуализация (Рекомендуется для 99% пользователей): Без риска для основной macOS.
    • Для Mac M1/M2/M3 используйте бесплатный UTM или коммерческий Parallels Desktop. Скачайте ARM64-образ (например, Ubuntu Server или Debian ARM).
    • Для Mac Intel используйте бесплатный VirtualBox или VMware Fusion.
  2. Проект Asahi Linux (Для нативной установки на Apple Silicon M1/M2):

    Это полноценный порт Linux для процессоров Apple. Установка запускается прямо из терминала macOS одной командой:

    curl https://alx.sh | sh

    Скрипт сам безопасно изменит разделы диска и установит дистрибутив (по умолчанию Fedora Remix).

  3. Dual Boot через Boot Camp (Только для старых Mac на процессорах Intel):

    Запишите образ Linux (Ubuntu/Mint) на флешку через программу Etcher, перезагрузите Mac с зажатой клавишей Option (Alt) и выберите загрузку с USB для установки рядом с macOS.

Midnight Commander (команда mc) — двухпанельный файловый менеджер для терминала, наследник Norton Commander. Он незаменим при работе по SSH: перемещение, копирование, редактирование и просмотр файлов делаются клавишами, без длинных путей в командной строке.

Как читать сочетания: запись вида Ctrl + X, then C означает последовательное нажатие — сначала Ctrl + X, отпустить, затем C. На macOS клавиша Alt в терминале обычно требует включить опцию «Use Option as Meta key» (Terminal / iTerm2), иначе Alt-сочетания не сработают.
